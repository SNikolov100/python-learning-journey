# Python Fundamentals

This directory contains exercises, labs, exam preparation materials, and small projects completed during my Python Fundamentals training.

The materials were originally stored in several separate repositories. They are now organized together as part of my main [Python Learning Journey](../../README.md) repository.

## Course Overview

The Python Fundamentals course builds on the introductory knowledge gained from Python Basics and focuses on writing more structured programs, working with collections, processing text, and solving practical programming problems.

The directory includes lecture examples, laboratory exercises, additional exercises, exam preparation tasks, and personal practice projects.

## Topics Covered

The main topics covered in this course include:

- Basic syntax, conditional statements, and loops
- Data types and variables
- Lists and list operations
- Functions
- Advanced list operations
- Objects and classes
- Dictionaries
- Text processing
- Regular expressions
- Problem-solving and algorithmic thinking
- Code organization and debugging

## Directory Structure

The course materials are organized by topic and type of activity:

- **Lectures** – examples and explanations introduced during the lessons
- **Labs** – guided practical exercises
- **Exercises** – independent problem-solving tasks
- **Additional exercises** – extra practice for reinforcing the studied concepts
- **Mid exam** – preparation tasks and exam solutions
- **Final exam** – final assessment materials
- **Exam preparation** – practice problems completed before the exams
