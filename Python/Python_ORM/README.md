# Python ORM

This directory contains laboratory exercises, independent exercises, exam preparation materials, and practical tasks completed during my Python ORM training.

The course focuses on working with relational databases through Python and the Django Object-Relational Mapper.

## Course Overview

The Python ORM course connects relational database concepts with application development in Django.

Instead of writing every database operation directly in SQL, the Django ORM allows database tables, relationships, and queries to be represented through Python classes, objects, and methods.

The materials progress from introductory ORM concepts and Django models to migrations, relationships, inheritance, customization, and advanced database queries.
