# Python Advanced

This directory contains exercises, practical assignments, exam preparation materials, and solutions completed during my Python Advanced training.

The course represents the next stage of my Python learning journey after Python Fundamentals. It focuses on more advanced data structures, complex problem-solving, file operations, error handling, and writing better-organized Python programs.

## Course Overview

Python Advanced develops a deeper understanding of the Python language and introduces techniques for solving larger and more complex programming problems.

The materials in this directory include laboratory exercises, independent exercises, homework assignments, exam preparation tasks, presentations, and solutions from the practical exam.

## Topics Covered

The main topics covered in this course include:

- Lists as stacks and queues
- Tuples
- Sets
- Multidimensional lists
- Advanced functions
- Error handling
- File handling
- Working with nested data structures
- Comprehensions
- Function arguments
- Recursion
- Reading from and writing to files
- Problem-solving with complex collections
- Exam preparation and practical assessment

## Directory Structure

The course materials are organized into topic-based directories.

- Stack operations
- Queue operations

### Tuples and Sets

Exercises involving:

- Immutable collections

### Multidimensional Lists

Exercises involving:

- Matrices
- Nested lists
- Row and column operations

- Diagonal calculations

### Advanced Functions

Exercises involving:

- Positional and keyword arguments
- Arbitrary numbers of arguments
- Packing and unpacking

- Recursion
- Function composition
- More reusable program structure

### Error Handling

Exercises involving:

- Runtime error handling

### File Handling

Exercises involving:

- Processing file content
- Working with file paths
