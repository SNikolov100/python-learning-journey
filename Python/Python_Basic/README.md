# Python Basics

This directory contains laboratory exercises, independent exercises, additional practice tasks, and exam materials completed during my first programming course with Python.

The course marks the beginning of my programming learning journey and introduces the fundamental concepts required for writing and understanding basic computer programs.

## Course Overview

Python Basics focuses on developing fundamental programming skills and logical thinking.

The course starts with simple calculations, variables, and console input and output. It then progresses through conditional statements, loops, nested structures, and practical problem-solving tasks.

The materials in this directory include guided laboratory exercises, independent exercises, additional practice, and exam solutions.

## Topics Covered

The main topics covered in this course include:

- First steps in programming
- Basic Python syntax
- Variables
- Numeric and text data
- Arithmetic operations
- Reading input from the console
- Displaying formatted output
- Simple conditional statements
- Advanced conditional statements
- Nested conditions
- `for` loops
- `while` loops
- Nested loops
- Basic calculations
- Logical thinking
- Problem-solving with sequential steps

## Directory Structure

The course materials are organized by topic and type of activity.

### First Steps in Coding

Introductory exercises involving:

- Variables
- Numeric calculations
- Reading user input
- Printing results
- Converting input values
- Solving problems with sequential operations

### Conditional Statements

Exercises involving:

- Boolean conditions
- Comparison operators
- `if`, `elif`, and `else`
- Making decisions based on user input
- Validating simple conditions
- Choosing between alternative program paths

### Advanced Conditional Statements

Exercises involving:

- Combining multiple conditions
- Logical operators
- Nested conditional statements
- More complex decision-making
- Processing several related input values

### For Loops

Exercises involving:

- Repeating operations a fixed number of times
- Working with numeric ranges
- Accumulating totals
- Finding minimum and maximum values
- Processing sequences of input data

### While Loops

Exercises involving:

- Repeating operations while a condition remains true
- Processing an unknown number of inputs
- Using control values
- Stopping execution when a specific condition is reached

### Nested Loops

Exercises involving:

- Placing one loop inside another
- Generating combinations
- Processing structured repetitions
- Solving more complex iterative problems

## Laboratory Exercises

The laboratory directories contain guided tasks completed while learning each new topic.

These exercises introduce the syntax and demonstrate how the programming concepts work through smaller practical examples.

## Independent Exercises

The exercise directories contain tasks completed independently after each laboratory session.

These tasks reinforce the studied concepts and develop the ability to:

- Read and understand a problem statement
- Identify the required input and output
- Select suitable variables and operations
- Build the solution step by step
- Test the solution with different input values
- Find and correct logical errors
