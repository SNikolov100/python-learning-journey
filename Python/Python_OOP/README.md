# Python OOP

This directory contains exercises and practical tasks completed during my Python Object-Oriented Programming training.

The course is part of my Python learning journey and focuses on designing structured, reusable, and maintainable applications by applying the principles of object-oriented programming.

## Course Overview

Python OOP introduces a different approach to program design. Instead of organizing an application only around separate functions and data structures, object-oriented programming combines related data and behavior into classes and objects.

The materials in this directory follow the progression from basic class definitions to inheritance, encapsulation, polymorphism, and abstraction.

## Object-Oriented Programming Principles

The course develops practical understanding of the main OOP principles:

### Encapsulation

Combining related data and behavior inside a class while controlling access to the internal object state.

### Inheritance

Creating new classes from existing classes to reuse and extend common behavior.

### Polymorphism

Using a common interface with objects that provide different implementations of the same behavior.

### Abstraction

Representing the essential behavior of an object while hiding unnecessary implementation details.
