# PostgreSQL

This directory contains laboratory exercises, independent exercises, exam preparation materials, and practical tasks completed during my PostgreSQL training.

The course introduces relational databases and develops practical skills in designing database structures, retrieving and modifying data, creating relationships, and writing more advanced SQL queries.

## Course Overview

The PostgreSQL course focuses on the principles of relational databases and the practical use of SQL.

The materials progress from basic database operations to data aggregation, table relationships, subqueries, joins, database programmability, and practical exam preparation.

The course also provides the database knowledge required for working with Django models and the Django ORM.

## Topics Covered

The main topics covered in this course include:

- Relational database concepts
- Database tables
- Columns and data types
- Primary keys
- Foreign keys
- Database constraints
- Creating and modifying tables
- Inserting data
- Selecting data
- Updating records
- Deleting records
- Filtering and sorting query results
- Aggregate functions
- Grouping data
- Table relationships
- Subqueries
- Joins
- Database programmability
- Transactions
- Exam preparation and practical assessment

## Directory Structure

The course materials are organized into laboratory exercises, independent exercises, and exam preparation directories.

### Database Exercises and Labs

- Creating databases and tables
- Selecting suitable data types

- Retrieving stored information
- Updating existing records

Exercises involving:

- Aggregate functions
- `COUNT`
- `SUM`
- `AVG`
- `MIN`
- `MAX`
- Grouping records with `GROUP BY`
- Filtering grouped results with `HAVING`

### Table Relations

Exercises involving:

- One-to-one relationships
- One-to-many relationships
- Many-to-many relationships
- Primary and foreign keys
- Referential integrity
- Connecting related records across multiple tables
- Designing normalized relational structures

### Subqueries and Joins

Exercises involving:

- Inner joins
- Left joins
- Right joins
- Full joins
- Combining information from related tables
- Nested queries

### Database Programmability

Exercises involving:

- Functions
- Stored procedures
- Reusable database operations
- Database-side calculations
- Transactions
- Organizing more complex SQL logic
- Applying database behavior close to the stored data

## Exam Preparation

The `Exams_practises` directory contains tasks used to review and combine the main course topics before the practical assessment.

These exercises require:

- Understanding an existing database structure
- Creating and modifying database objects
- Retrieving information from multiple tables
- Selecting suitable joins and subqueries
- Aggregating and grouping data
- Producing accurate query results
- Testing SQL statements carefully

## Practical Exam

The `Exam` directory contains materials and solutions related to the practical course assessment.

The exam tasks combine database design, SQL queries, table relationships, aggregation, joins, subqueries, and database programmability.

## Relationship to Django

The knowledge developed in this course supports later work with Django and the Django ORM.

PostgreSQL concepts such as tables, columns, primary keys, foreign keys, constraints, and relationships correspond to important Django concepts such as:

- Models
- Model fields
- Primary keys
- `ForeignKey`
- `OneToOneField`
- `ManyToManyField`
- QuerySets
- Migrations
- Database constraints

Understanding the underlying relational database makes it easier to design effective Django models and write more efficient application queries.
