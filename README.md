# Python Learning Journey

Welcome to my programming learning repository.

This repository brings together the exercises, laboratory tasks, exam preparation materials, small projects, and practical assessments completed throughout my education in Python, PostgreSQL, the Django ORM, and Django web development.

The purpose of this repository is to document my progress from the first steps in programming to building structured database-driven web applications.

## Learning Path

My learning path is organized into the following stages:

1. Python Basics
2. Python Fundamentals
3. Python Advanced
4. Python Object-Oriented Programming
5. PostgreSQL
6. Python and Django ORM
7. Django Basics

Each main directory contains a dedicated README file with a detailed description of the covered topics, exercises, projects, examinations, and skills developed during that stage.

## Learning Progression

The repository documents a gradual transition from basic programming to database-driven web development:

```text
Python Basics
    ↓
Python Fundamentals
    ↓
Python Advanced
    ↓
Python OOP
    ↓
PostgreSQL
    ↓
Python ORM
    ↓
Django Web Development
```

### Programming Foundations

Python Basics and Python Fundamentals introduced syntax, conditions, loops, collections, functions, text processing, and logical problem-solving.

### Advanced Python

Python Advanced developed experience with complex collections, advanced functions, recursion, error handling, and file operations.

### Object-Oriented Design

Python OOP introduced classes, objects, inheritance, encapsulation, polymorphism, abstraction, and reusable application design.

### Relational Databases

PostgreSQL introduced tables, relationships, constraints, SQL queries, aggregation, joins, subqueries, and database programmability.

### Object-Relational Mapping

Python ORM connected Python objects and Django models with relational database tables and records.

### Web Development

Django Basics combined routing, views, templates, forms, models, and HTTP communication into structured web applications.
